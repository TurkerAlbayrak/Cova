The high-performance, enterprise-grade Web Framework written in pure C.

Getting Started

Cova is designed to be lightweight but powerful. You can run it on Windows, Linux, and macOS.

Installation via Docker (Recommended)

git clone https://github.com/TurkerAlbayrak/Cova.git
cd Cova
docker compose up --build

Native Build

Ensure you have GCC and OpenSSL installed.

# Windows
.\build.bat

# Linux
make

Architecture

Cova uses a custom ThreadPool for handling thousands of concurrent requests efficiently. Rather than spawning a new thread or process for every request (which is heavy), Cova maintains a pool of worker threads. When a request arrives, the main thread assigns it to an idle worker.

Tip: You can adjust the number of threads in the threadpool_create(16) call in server.c to optimize for your specific CPU cores.

Routing & Requests

Cova supports dynamic routing, path parameters, and query strings.

void user_handler(Request *req, Response *res) {
    // Access Path Parameter (e.g. /users/:id)
    const char *user_id = request_param(req, "id");
    
    // Access Query String (e.g. ?sort=desc)
    const char *sort_mode = request_query(req, "sort");
    
    response_json(res, "{\"status\": \"success\"}");
}

// In main:
app_get(&app, "/users/:id", user_handler);

Responses & Static Files

You can send JSON, HTML, plain text, or serve entire static directories.

// Serve a single file
response_file(res, "public/index.html");

// Serve an entire directory globally (in main)
app_static(&app, "/assets", "./public/assets");

The ORM (Object-Relational Mapping)

The crown jewel of Cova is its C-native ORM. You do not need to write raw SQL strings.

typedef struct {
    int id;
    char title[100];
    int is_published;
} Post;

ORM_FIELD_MAP(Post) = {
    ORM_INT_FIELD(Post, id, "PRIMARY KEY AUTOINCREMENT"),
    ORM_STRING_FIELD(Post, title, 100, "NOT NULL"),
    ORM_INT_FIELD(Post, is_published, "DEFAULT 0"),
    ORM_END_FIELDS
};

ORM_MODEL(PostModel, "posts", Post, __orm_fields_Post);

// Auto-migrate tables
orm_auto_migrate(&PostModel);

// Insert data
Post new_post = {0, "Cova is awesome!", 1};
orm_insert(&PostModel, &new_post);

JWT Authentication

Secure your routes using JSON Web Tokens.

// 1. Set secret in main()
app_set_jwt_secret(&app, "super_secret");

// 2. Generate token on login
char *token = jwt_generate("{\"user\":\"admin\"}", "super_secret");

// 3. Protect routes via middleware
void secure_route(Request *req, Response *res) {
    if (!jwt_middleware(req, res)) return;
    response_text(res, "Secret Data");
}

WebSockets

Cova natively supports the WebSocket protocol for real-time applications.

void chat_handler(Request *req, Response *res) {
    if (ws_handshake(req, res)) {
        while (1) {
            char *msg = ws_read_frame(res->client_socket);
            if (!msg) break;
            
            ws_send_text(res->client_socket, msg); // Echo
            cova_free(msg);
        }
    }
}

Rate Limiting

Prevent brute-force and DDoS attacks globally across your app.

// Limit to 100 requests per second per IP
app_set_rate_limit(&app, 100);
app_use(&app, rate_limit_middleware);

Docker Deployment

Our Dockerfile uses Alpine Linux for incredibly small image sizes. Run docker compose up --build to start the server. The public/ folder is mounted as a volume so you can edit static files without rebuilding.

Memory Tracking

Cova overrides standard malloc and free with cova_malloc and cova_free. When the server gracefully shuts down (CTRL+C), it prints a complete Memory Leak report, helping you write safe C code.
